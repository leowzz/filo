## 16. UI 结构

当前设计以用户提供的 macOS Finder 浅色截图为准，覆盖原任务书中的深色风格要求。现阶段只提供浅色，不跟随系统切换深浅，也不提供主题切换入口；主题切换留待后续版本。

界面约定：

* 原生 macOS 红黄绿窗口按钮，工具栏与标题栏融合，并保留窗口拖动区域。
* 浅灰侧栏、白色内容区、系统字体；蓝色图标与文件选中态，侧栏选中项使用中性灰。
* 顶部单行工具栏：前进/后退、当前目录名称、文件操作、详情开关、刷新和当前目录筛选。
* 文件列表紧凑排列，交替行底色，列顺序为名称、大小、种类、修改时间。
* 底部提供可点击的路径导航与项目数量；详情面板默认收起，需要时展开。
* 概览保持存储信息布局，只显示实际数据，不填充虚构的容量或使用率。
* 弹窗、操作菜单、偏好设置、加载/空列表/错误状态全部使用浅色。
* 右键侧栏位置支持「移除位置…」，确认只移除连接配置。
* 右键侧栏位置打开「编辑连接…」；支持显示名称、只读开关和通过原生选择器更换本地目录。取消选择不保存，保存后立即刷新权限与列表。

* 表格文件列表。

* 刷新。
* 创建目录。

* 删除文件。

* 传输任务抽屉。
* Loading、Empty、Error 状态。
* 右键菜单或操作菜单。

本地单文件传输现已提供工具栏/操作菜单入口、目标位置与子目录选择、文件名输入、传输任务页进度及取消。S3 和目录递归传输仍待实现。
