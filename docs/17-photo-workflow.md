# 摄影导入与审图方案

状态：首版已实现，macOS 本地及 SMB 目录审图已验证，真实 SD、其他远程服务、Windows 和 LRC 回读待验收。核查日期：2026-10-20。

拷卡和审图独立：审图不读取拷卡记录，拷卡不创建审图任务或改变评分。文件浏览器的「进入审图」可直接审阅已配置存储中的当前目录，文件夹右键菜单也提供此入口，支持本地、S3、FTP/FTPS、SFTP 和 SMB。目录的 `.filo/review.json` 保存排序方式、当前照片的相对路径及上次导出位置与结果；星级与旗标保存在照片对应的 XMP 中，不记录“已审阅”状态。重新进入会恢复位置并扫描新增照片；`.filo` 不参与照片扫描。预览使用应用固定缓存目录中的磁盘缓存，默认上限 1 GB、30 天未访问过期，按 LRU 清理；可在设置中调整容量、过期时间或清空缓存，不写入照片目录。只读存储无法保存审图进度。

侧栏的「拷卡」入口保留独立导入流程；「审图」入口可打开系统目录或分别指定 JPG/RAW 根目录。原有批次清单 `.filo/sessions`、`.filo/reviews` 保持兼容。

Filo 通过独立的「审图」和「拷卡」入口，提供从 SD 卡归档到 NAS、快速初选，以及把选择结果交给 Lightroom Classic 的流程。精修继续在 LRC 中完成。核心对象是一次拍摄的导入批次和一张照片；一张照片可以同时关联 NEF、JPG 及附属文件。

## 使用流程

已确认：通常使用主卡，副卡只作备份。拷卡使用系统挂载目录，审图可直接使用 Filo 内已配置的存储连接。

1. 插入主卡，打开「从存储卡导入」，选择拍摄批次、归档位置和整理方案，预览实际目标路径。
2. 扫描 DCIM，识别同目录、同名的 NEF/JPG；显示新照片、已导入照片、缺少配对文件和冲突。
3. 复制到两个配置好的目标根目录，完成内容校验。保留 SD 卡文件。

独立审图流程：

1. 浏览已配置存储的任意照片目录，点击「进入审图」，或右键文件夹进入审图。也可在侧栏的「审图」中选择一个照片目录打开，无需配置配对目录或经过 Filo 拷卡。目录名称自动作为审图名称。
2. 同一目录内的同名 NEF/JPG 自动配对，元数据明显矛盾时分开审阅。「仅查看 RAW」隐藏只有 JPG 的照片，并使用 NEF 内嵌预览；打开目录前和审图时都可切换，不改变照片身份、星级或旗标。目录模式下，标记成功表示 XMP 已提交；写入失败会提示重试，检测到其他应用更新时不覆盖。
3. 审图结束使用「导出到目录」，通过表单选择筛选条件（默认 ≥3 星）并批量复制 RAW 到所选目录；审图记录保存导出位置。

副卡不作为每次导入的必选步骤。以后从副卡导入时，内容相同的文件关联已有归档；主卡遗漏或失败的文件可以补齐，不能只凭文件名跳过。

## 文件布局与照片配对

分别配置「JPG 目录」和「RAW 目录」，两边使用相同的整理规则。下面以「按拍摄日期」为例，不代表用户现有 NAS 路径：

```text
图库扫描的根目录/
  2026/2026-10-19/DSC_6166.JPG

图库扫描范围之外的 RAW 根目录/
  2026/2026-10-19/DSC_6166.NEF
  2026/2026-10-19/DSC_6166.xmp
  .filo/sessions/批次ID.json
```

仅把 RAW/JPG 拆成两个子目录不一定能消除重复：图库若扫描共同父目录，仍会索引两份。要把 RAW 根目录放在其扫描范围之外，或者使用图库本身明确支持的排除规则。

### 整理方案

导入界面提供以下四个预设，选中后直接展示 JPG 和 RAW 两边的完整目标路径。示例源文件为 `DCIM/107NZ5_2/DSC_6166.{JPG,NEF}`，拍摄日期为 2026-10-19；表中的路径相对于各自目标根目录。

| 预设 | 目标路径示例（RAW） | 原始文件夹层级 | 适合场景 |
| --- | --- | --- | --- |
| 按拍摄日期（推荐） | `2026/2026-10-19/DSC_6166.NEF` | 不保留 | 多次拷卡统一按拍摄日归档，不关心相机文件夹编号 |
| 按拍摄日期并保留层级 | `2026/2026-10-19/107NZ5_2/DSC_6166.NEF` | 保留 | 按日期查找，同时保留相机原始目录关系 |
| 按批次并保留层级 | `2026-10-19_旅行/107NZ5_2/DSC_6166.NEF` | 保留 | 一次旅行或拍摄项目放在一起，可以跨多个拍摄日 |
| 保留原始目录 | `107NZ5_2/DSC_6166.NEF` | 保留 | 沿用现有相机目录组织，不新增日期或批次文件夹 |

预设由「归档方式：拍摄日期 / 自定义批次 / 不新增分组」和「保留原始文件夹层级」开关组成，可单独调整。例如选择按批次后关闭保留层级，得到 `2026-10-19_旅行/DSC_6166.NEF`。首版使用上述固定日期结构，不增加自由编写路径模板的配置。

「保留层级」保留相对于扫描根目录的路径：识别到 DCIM 时，以 DCIM 为根，因此保留 `107NZ5_2` 及其下级目录，不带入盘符、卷名或 DCIM 本身；手动选择其他来源目录时，以所选目录为根。扫描根和实际结果在路径预览中明确展示。关闭后只保留文件名，原始路径仍记在批次记录中。

按日期以每张照片的拍摄日期分组，一张卡跨多天会生成多个日期目录。配对照片优先读取 NEF 的拍摄时间，缺失时使用 JPG；两者日期冲突列为待处理，确定后整组使用同一日期。采用相机记录的日期，不随 Windows/macOS 当前时区改变。缺失或无效日期进入「未知拍摄日期」，可以在导入前统一指定日期；不静默用文件修改时间或导入时间替代。批次名称是可编辑文本，即使带日期，也不代表批次内所有照片都在当天拍摄。

同名处理先判定是否已归档：内容相同的文件关联已有记录并补齐缺失成员；内容不同则保留双方，给整张照片的文件统一追加编号，例如 `DSC_6166_2.NEF`、`DSC_6166_2.JPG`、`DSC_6166_2.xmp`，不覆盖原有文件。编号需同时避开两个目标根目录的冲突，导入前展示并保存计划；重试沿用原计划，不能给 RAW/JPG 分别编号。原始文件名默认保留，仅在冲突时改名。

导入批次是记录单位，不一定对应单独的磁盘目录：一个批次可以跨多个日期目录，一个日期目录也可以接收多个批次。再次导入已归档照片沿用已有位置；调整整理预设只影响新文件，不自动重排已归档或已交给 LRC 的文件。

### 照片配对

配对规则：同一来源目录中的同名 NEF/JPG 为候选对，读取到拍摄时间、相机信息时检查明显矛盾；文件名相同但来自其他目录或批次的照片不自动合并。只有 JPG、只有 NEF 的照片仍可导入和审阅。备份卡的相同文件按内容摘要去重，再关联已有照片，而不是通过卡名推断相同。

「一张照片」拥有一个稳定 ID，星级与旗标属于照片。RAW/JPG 路径只是它的文件成员；不能用 `DSC_6166` 作为全局 ID，也不能把两个不同格式的文件当成字节相同的重复文件。

## 拷卡需要补齐的能力

- **保存导入预设**：主卡别名、JPG/RAW 两个目标根目录、归档方式、是否保留原始层级和上次批次选择。挂载路径变化或卡格式化后允许重新关联；卷名和卷标识仅帮助找卡，不作为去重依据。
- **逐文件导入记录**：记录来源、内容摘要、目标位置、校验结果以及所属照片。重插卡时识别已导入内容；文件名和大小只用于缩小候选范围，最后由内容校验确认。
- **恢复中断批次**：重新检查已提交的目标和源文件，继续缺失或失败的文件。已经写入而记录未落盘的文件也需重新核对。第一版按文件恢复，未完成的大文件重新复制。
- **配对完成状态**：NEF 已完成而 JPG 失败时显示部分完成；两份文件无法用一个跨目录原子操作提交，不能提前声称整张照片已归档。
- **记录不依赖普通传输历史**：普通传输列表只保留最近 200 条，无法承担长期防重复导入。
- **只复制主卡**：成功表示指定目标已完成复制和校验，不自动清卡，也不把副卡标为已核验。

重复判定还需检查归档目标仍然存在。主动清理过的照片保留处理记录，避免下次插入主卡或备份卡又自动导回来；恢复这些照片是显式操作。

## 快速审图

工作区使用大图、底部胶片带和紧凑操作栏。全屏作为可选模式，状态和快捷键在普通窗口中同样可用。保留审图进度、筛选条件及上次位置。

全屏按钮右侧的设置按钮可直接打开设置页；从审图进入时，设置顶部显示「返回审图」。往返保留当前照片、模式、筛选和放大位置，设置修改即时生效。进入设置会退出全屏并取消本次自动前进，设置期间审图快捷键暂停；已经提交的标记继续保存。通过侧栏转往其他页面后结束此次快捷返回。

审图提供两个便捷模式，原有筛选和自动前进开关保留在「自由审图」中：

- **旗标快筛**：浏览全部照片（仍遵循「仅查看 RAW」开关），点击「留用」或「排除」保存后自动下一张。已标照片保留在序列中，可用左右按钮、方向键或胶片带回看纠错。再次点击已选旗标会清除标记并停留。
- **留用星级**：只浏览标为留用的照片，不按星级隐藏已评分照片。点击星星或「升一星」后，默认等待 500 ms 自动下一张；连续调星从最后一次操作重新计时。等待时间可在模式内选择 200–2000 ms，并记住本机设置。清除星级、手动切图、切换模式或离开窗口会取消待执行的跳转。自动切图等标记保存成功，最后一张停留，不循环回开头。

便捷模式的点击和快捷键采用相同规则：快筛只操作旗标，留用星级只操作评分。撤销会回到「自由审图」并显示被撤销的照片，方便检查。

以下为自由审图操作：

| 按键或操作 | 行为 |
| --- | --- |
| 左右方向键 | 上一张、下一张照片 |
| 1–5 / 0 | 设置星级 / 清除星级 |
| 点击星级 | 设置该星级，再次点击当前星级清零 |
| ] / [ | 提高一星 / 降低一星，停留在当前照片 |
| Shift + ] / Shift + [ | 提高一星 / 降低一星后进入下一张 |
| C / X | 保留 / 待删除，相邻双键；再次按同一键取消对应旗标 |
| P / U | 兼容保留快捷键 / 清除旗标 |
| 点击保留或待删除 | 设置旗标，再次点击已选旗标关闭 |
| 自动前进开关 | 使用数字键设置星级或 C/X/P/U 标记后进入下一张 |
| Shift + 数字键或 C/X/P/U | 临时执行评分或标记后前进 |
| Cmd/Ctrl + Z | 撤销上次标记，并回到对应照片 |
| 空格 / Z | 适应窗口与预览图原尺寸切换，放大后图片居中；自由审图、旗标快筛和星级筛选均可用 |
| Esc | 退出全屏或返回审图记录 |

相对调整星级限制在 0–5 星：0 星按 `]` 变为 1 星，5 星再按 `]` 保持 5 星，0 星按 `[` 保持 0 星，不循环。`[`、`]` 即使打开自动前进也停留当前照片，便于连续调两三档；需要一边加星一边翻页时使用 Shift 组合，达到星级边界也会按明确的前进指令翻页。只有评分实际变化才生成评分撤销记录。输入框内不触发审图快捷键。

「待删除」只是旗标，不执行文件删除。星级与旗标独立，例如一张 3 星照片可暂时标为待删除而不丢失评分。浏览照片不会新增任何标记状态。

排序提供文件名、拍摄日期的升序与降序；拍摄日期使用相机记录的完整时间，同一时间按文件名排序，缺失日期排在末尾。首次选择日期排序时按需读取照片头并缓存，可取消，不改用文件修改时间。快捷筛选提供全部、无旗标、保留、待删除和 ≥3 星，点击会重置其他筛选条件；也可进一步调整星级门槛。审图序列覆盖所打开目录中的全部照片，不受文件列表当前已加载的 200 项限制。快速连按时把操作绑定到确定的照片 ID；评分键的长按重复不连续标记多张照片，异步响应不能把评分落到下一张。

优先使用配对 JPG 预览，没有 JPG 时使用 NEF 内嵌 JPEG；预取相邻少量照片，并限制缓存容量。高分辨率图按需读取，NAS 较慢时先展示已有预览。原尺寸指实际读取到的 JPG 或内嵌图尺寸；内嵌预览不足时提示，不能把放大的缩略图当作 RAW 像素级对焦检查。完整 RAW 解码及颜色精修留给 LRC。

第一版提供待删除筛选和导入排除信息；批量移入隔离目录可以后续增加。若增加清理，按照片处理 NEF、JPG、XMP 及已识别的附属文件，持久化部分成功结果和恢复路径。已交给 LRC 的文件不再自动搬移，避免目录引用失效。

### 动效与成功反馈

鼠标点击和键盘操作使用同一套反馈。每次实际改变星级或旗标，都有可辨认的动画；操作栏和胶片带持续显示最终状态，不能只靠转瞬即逝的提示判断操作是否成功。按用户选择采用强反馈：透明浮层直接叠加在图片下半部，升星时爆发彩纸、星屑与飘带，配合放大回弹的星级结果，星级越高越热烈。不单独预留反馈区域，不显示文件名、「已更新」「已评分」等说明，只显示星级或旗标结果。浮层没有卡片底色、遮罩或独立背景，不改变照片布局；短暂覆盖图片下半部后淡出，不拦截鼠标操作。

| 操作 | 动效与反馈 |
| --- | --- |
| 逐级升星 | 新增星星填充暖金色并回弹；图片下半部的大星星和评分悬浮弹出，环形冲击波伴随彩纸、星屑和飘带喷散，1→2、2→3、3→4、4→5 逐级增加粒子密度和范围 |
| 一次跳升多级 | 控件中的新增星星按顺序点亮，间隔约 40ms；下方直接播放目标星级的爆发，评分值立即更新，不排队播放多个过期星级 |
| 达到五星 | 金色五星结果强回弹，先中心爆发，再从左右两侧喷出礼炮，追加一次中心星屑爆发；粒子旋转、飘落和消散，不触发全屏闪光或默认声音 |
| 降星或清零 | 被移除的星星轻微收缩，金色褪回轮廓；其余星星保持稳定 |
| 标记保留 | 图片下半部的绿色旗标悬浮弹出，配合薄荷绿纸片爆发和冲击波，出现「保留」结果，胶片带同步显示对应旗标 |
| 标记待删除 | 珊瑚红旗标像盖章一样落定，配合红色纸片和冲击波，出现「待删除」结果；原图保持原样 |
| 清除旗标 | 原旗标淡出，短暂显示「无旗标」，不暗示删除或恢复文件 |
| 撤销 | 回到对应照片并反向更新星级或旗标，短暂显示「撤销」 |

「设置 → 审图 → 审图动画时长」统一控制所有模式的旗标、星级与撤销反馈，默认 500ms，可选 100–2000ms，并记住本机设置。结果提示、控件点亮、粒子、入场和退场均按该时长同比例缩放。采用统一的动作语言，通过粒子密度、范围和五星多段爆发体现级别差异。达到 0/5 星边界或重复设置相同状态时，不重放操作成功动画，不制造新操作记录。

交互按下立即给出轻微按压反馈，状态变化可先乐观显示；目录模式须等 XMP 提交后才显示标记成功，旧批次模式须等本机持久化确认并单独显示 NAS 同步状态。保存失败时撤回对应的未保存状态，提示具体照片和重试入口；旧请求失败不能覆盖后续已成功的新操作。

连续操作立即更新到最新状态，各颗星分别衔接或重启自身动画，不排队播放过期反馈，不锁住输入。同类升星可以叠加粒子但必须限制总量；切换到不同旗标时清除旧动作的粒子及尚未触发的礼炮，重置、页面隐藏或启用减少动态效果时立即清理。自动前进至少等待配置的动画时长；星级筛选取动画时长与模式内等待时间的较大值，并等待标记保存成功。旗标快筛保持后台保存、动画结束后切图；期间可继续操作，新的操作取代旧的自动前进计划。手动翻页立即响应。切换照片时清除全部旧浮层、粒子与延迟动作，已经翻页后返回的旧请求不能在当前照片上播放反馈。

遵循系统「减少动态效果」，关闭粒子、礼炮、冲击波及位移缩放，改用短淡入淡出和明确的图标、文字；旗标区别不能仅依赖颜色。读屏的操作结果只播报一次，不逐帧播报动画状态。动效演示只验证视觉节奏，不作为本机保存或 NAS 同步验证。

## 把结果交给 Lightroom Classic

NEF 使用同目录同名的 `DSC_6166.xmp` 保存交换元数据。Adobe 说明专有 RAW 的 XMP 使用旁车文件，而 JPEG 等格式通常把元数据写在文件内部。因此第一版以 RAW → LRC 为主线，不承诺一个独立 JPG 旁车文件就能让所有图库识别星级。[Adobe 元数据说明](https://helpx.adobe.com/lightroom-classic/desktop/organize-photos-in-lightroom-classic/metadata-basics-actions.html)

LRC 从 13.2 起支持在 XMP 中保存旗标，因此设计目标是传递星级及保留/待删除状态；必须使用真实 NEF 在用户安装的 LRC 版本中验证写入、导入和回读，不能把通用 XMP 的负星级直接假定为 LRC 待删除旗标。[Adobe 评分与旗标说明](https://helpx.adobe.com/lightroom-classic/desktop/organize-photos-in-lightroom-classic/flag-label-rate-photos.html)

审图结束后的「导出到目录」提供星级与旗标筛选表单，默认星级大于等于 3、旗标不限。星级可选大于等于、等于、小于等于或不限，包含未评分（0 星）；旗标可选不限、保留、待删除或无旗标。条件独立于审图页的显示筛选。导出保留 RAW 在审图目录中的相对路径，不复制 JPG 或 XMP，源文件不移动。目标应选择照片来源之外的目录。可添加多个常用导出目录，点击切换，列表及当前选择保存在本机，下次打开自动选中。选择目录仅更新表单，点击「开始导出」才复制文件。

导出逐文件校验；目标已有相同内容时跳过，不同内容的同名文件保留并报告失败。完成后显示复制、跳过和失败数量，部分失败可重试。上次导出路径、时间和结果保存在审图记录中，目录审图也会写入 `.filo/review.json`，重新打开可查看。旧审图记录无导出字段时仍可正常读取。

NAS 原片与 LRC 目录数据库分别配置：原片可以放在网络位置，工作中的 catalog 需要放在本地磁盘。[Adobe catalog FAQ](https://helpx.adobe.com/lightroom-classic/desktop/technical-support/workflow-issues/catalog-issues/catalog-faq-lightroom.html)

已存在的 XMP 必须保留其他应用写入的字段；写回前检查文件版本，冲突时保留两边内容和待处理状态。LRC 15.0 起还可能使用 `.acr` 旁车，文件整理时必须保留它。[Adobe 元数据说明](https://helpx.adobe.com/lightroom-classic/desktop/organize-photos-in-lightroom-classic/metadata-basics-actions.html)

## Windows 与 macOS 共用 NAS

拷卡使用系统挂载的 SMB 目录；目录审图也可直接使用 Filo 内的存储连接。交给 LRC 仍需一个操作系统可访问的 NAS 路径，Filo 的内部连接 ID 不能直接成为 LRC 文件路径。

目录模式的 `.filo/review.json` 只有 `sort` 和 `current` 两个字段，当前位置使用照片相对路径，换电脑后仍可恢复。星级与旗标从对应 XMP 恢复；撤销历史不写入目录进度文件。旧版目录记录中的标记会先迁移到 XMP，再精简进度文件；迁移遇到冲突时保留旧记录。拷卡记录使用 RAW 根目录下 `.filo/sessions/<批次ID>.json`；原有分别指定 JPG/RAW 的审图批次继续使用 `.filo/reviews/<审图ID>.json` 和手动恢复。本机 SQLite 为目录模式提供索引与缓存，为旧批次保存工作状态。

目录模式的标记及撤销结果直接写入 XMP，排序和当前位置写入进度文件，存储断线或不可写时显示失败。其他应用更新 XMP 或其他电脑更新进度文件时保留原文件；「继续审图」会重新读取目录记录，冲突提示中的「重新载入目录」会等旧保存请求结束后再恢复最新状态。旧批次仍先保存到本机再同步，换电脑只能恢复已同步的状态。不支持两台电脑同时编辑同一审图记录。

## 实施顺序与验收

第一阶段完成「主卡 → 两个 NAS 根目录 → 可恢复批次」：替代手工拷卡和分离脚本。第二阶段完成配对审图、快捷键、评分持久化与 XMP 交接。第三阶段再加入 Filo 内 SMB 的 LRC 路径映射、精确子集导入插件、并排比较和成组清理。

第一版闭环需覆盖这些实际情况：

- `DSC_6166.JPG` 与 `DSC_6166.NEF` 分开归档，审图只出现一次；图库仅扫描 JPG 所在范围。
- 四种整理预设与保留层级开关产生预览中的路径；跨日照片分别归档，日期缺失或冲突不会被静默替换。
- 取消原始层级后遇到同名不同内容，整组统一改名；重试不重新编号，已归档照片不因预设变化被搬移。
- 再插主卡、再插备份卡不会重复归档；不同批次同名但内容不同的照片不会覆盖或误合并。
- NAS 断线、拔卡或程序退出后，能识别已提交的文件与不完整配对，重试不会生成重复副本。
- 连续评分、自动前进、筛选、撤销和重启后恢复正确；超过 200 张照片仍能审完整个批次。
- `[`、`]` 在 0–5 星范围内逐级调整并停留当前照片；Shift 组合只前进一次，长按、输入框焦点和异步保存不会误标其他照片。
- 鼠标和键盘的每一级升星、降星、旗标切换均有对应反馈；透明浮层只短暂覆盖图片下半部，不预留独立区域或显示文件名等说明；连按、撤销和自动前进不会滞留旧动画或误指向下一张照片，减少动态效果模式仍能看清操作结果。
- 成功提示以对应保存位置的提交结果为准；模拟目录不可写、本机写入失败、NAS 断线和响应乱序时，不显示虚假成功、不覆盖后续操作。
- macOS 同步后，Windows 重新关联根目录可以继续审图；不同机器的挂载路径不影响照片身份。
- NEF 的 0–5 星和三种旗标在目标 LRC 版本中正确导入；已有修图字段和 `.acr` 文件保持完整。
- 「准备完成」「已归档」「NAS 待同步」与实际结果一致；待删除标记不删除任何源文件。


## 当前验证与边界

本机自动化覆盖双目录校验、统一冲突编号、内容去重、缺失成员补齐、来源变化、目标提交后的记录恢复、整理预设与跨日日期、独立目录审图、SQLite 保存失败、NAS 断线与记录冲突、换电脑重新关联、241 张序列及 XMP 字段保留。目录模式补充验证子目录内保存、全新数据库自动恢复、复制目录隔离、新照片扫描、只读与写入失败，以及远程虚拟目录的存储接口替身测试。浏览器使用模拟 IPC 验证目录入口、快捷键、自动前进、撤销、保存失败重试、输入框焦点、减少动态效果和窄窗口布局；实际文件与 SQLite 由 Rust 测试验证。

审图只扫描所选目录，不复制原片。未知日期不阻止独立审图。普通预览最大 2400px，原尺寸按需读取 JPG 或 NEF 内嵌图；JPG 上限 64 MiB，NEF 内嵌 JPEG 上限 20 MiB。进入目录会读取 XMP 中的星级和旗标，浏览本身不改写 XMP；明确修改星级或旗标时才提交对应旁车文件，并保留其他元数据。旧批次仍在明确「准备 LRC 导入」时写 XMP。

进入审图前先递归列出文件；单独的 RAW/JPG 不预读照片内容，只对新增或变化的同名 NEF/JPG 读取元数据校验配对，未变化的分组复用原记录。界面显示连接、列出照片、整理照片和保存记录的阶段；扫描可以取消，单个读取步骤超过 30 秒会提示重试。发布进度文件时完成当前写入，不中途取消。回归测试覆盖 241 张 RAW 打开时零照片内容读取、按需预览、配对缓存与失效、冲突分组恢复，以及阻塞读取的取消和超时。

macOS 开发窗口已验证从已配置的本地及 SMB NEF 目录直接进入审图、显示预览、返回目录，以及目录内保存进度；SMB 扫描也已验证取消打开。其他远程目录模式已通过存储接口替身和模拟 IPC 检查；真实 S3/FTP/SFTP 服务、SD 卡、Windows 桌面、LRC 导入与回读仍需现场验收。NAS 或 XMP 冲突保留原文件，不自动选择版本。内置 SMB 映射、LRC 精确子集插件、并排比较与批量清理尚未实现。
