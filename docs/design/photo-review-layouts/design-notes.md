# 审图布局探索

独立 HTML 交互原型；不修改应用源代码。用户授权全面探索布局。

## 设计取向

- 模式：Redesign · Overhaul。面向桌面连续选片，照片优先，约一臂观看距离。
- 五项校准：布局变化 7 / 动效 2 / 信息密度 7 / 图像依赖 10 / 品牌保留 6。
- 中性深灰画布 #151719，面板 #202326，分隔 #363a3f，正文 #e8ebee，次要文字 #a1a7af，选中蓝 #a8c5ee。保留/排除只作语义提示。
- 沿用原产品系统无衬线字体，中文优先 Microsoft YaHei / PingFang SC。4px 间距基准，6px 控件圆角，12px 浮层圆角。仅浮层使用阴影。140ms 状态变化，尊重减少动态效果。
- 保留操作语义：上一张/下一张、星级、留用、排除、撤销、筛选、排序、自动前进、缩略图、缩放。
- 重排：设置和导出低频入口进入弹层；菜单栏与标题栏不再分别占一整行。

## 四版

1. A 侧边工作台：右侧 236px 集中控制，照片画布全高，缩略图双列。
2. B 紧凑底片栏：顶部 40px、底部 128px；适合熟悉传统审图的用户，T 收起底片。
3. C 沉浸浮层：画布全高全宽；闲置自动隐藏顶部与底部浮层，T 临时唤出底片。浮层可覆盖少量图像，隐藏后无覆盖。
4. D 双侧翼：左侧 108px 纵向底片、右侧 180px 控制；把横向留白用于操作，较窄窗口上图片会受可用宽度约束。

## 数据与计算

主图裁自用户截图 (637,142)-(3203,1853)，保留截图中完整照片。其他样张裁自底部缩略图，仅供导航演示；不冒充原片。允许导入用户本地照片，全部在浏览器内处理。

占屏率 = contain 后实际图像矩形 / 原型工作区面积，不计方案切换导航。不含浏览器边框或系统任务栏。C 统计未扣除浮层遮挡，界面明确说明。

原布局参照截图应用区 3840×2088，上区 142、下区 235。按同比例上下空间计算同一照片、同一工作区的参照面积，因此增幅是估算，不是生产应用实测。缩放模式不报告误导性面积。

交互只改变原型内状态。会话内保留星级与标记，可导出 JSON；不改动原文件。不模拟 RAW 解码、EXIF、真实文件删除或后台保存。

- 浏览器目视检查四版布局；修复沉浸浮层页码换行。实际操作确认打星、留用、撤销和方案切换。
- 1920×1080 窗口下 A 方案图像矩形约 1526.7×1018，工作区占比 79.5%；对原截图同比例参照面积约 +49%。窄面板下占比随宽度约束下降，界面不宣称固定收益。
