# Filo 应用图标

采用用户选定的 C5 晴蓝方案：圆角文件夹、浅色 F 和较深的短横，纯色、无渐变、无阴影。SVG 是可编辑路径，不包含内嵌位图。外部留白透明，便于系统任务栏与侧栏显示。

## 资源与配色

- 唯一矢量源：`apps/desktop/src-tauri/icons/source.svg`。
- 主色：`#639FDF`；短横：`#4E7FB2`；F：`#FCFCFD`。
- 桌面资源：同目录下的 `32x32.png`、`64x64.png`、`128x128.png`、`128x128@2x.png`、`icon.png`、`icon.ico`、`icon.icns`。
- 侧栏品牌与浏览器 favicon 直接引用矢量源，Vite 在构建时处理资源路径。
- Windows 可执行文件、安装包及任务栏使用 Tauri 配置中的 ICO；macOS 应用与开发启动脚本使用 ICNS。

## 设计范围

模式为 Extension：按已批准的 C5 替换应用品牌资源，沿用现有字体、导航布局和交互。视觉变化 2/10、动效 1/10、界面密度 8/10、资源依赖 10/10、品牌忠实度 10/10。系统操作图标与存储服务商标识仍承担各自的功能含义。

## 重新生成

在项目根目录运行 `pnpm icons`。脚本使用项目锁定的 Tauri CLI 渲染 SVG，在临时目录生成各平台图标，然后只复制当前桌面应用所需的七个文件。修改 SVG 后应重新生成全部资源。
