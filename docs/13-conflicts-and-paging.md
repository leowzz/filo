# 同名冲突与大目录

复制、移动（含批量）和重命名弹窗提供「遇到同名项目」选项，本次操作统一使用所选策略，默认仍拒绝冲突。下载通过系统保存窗口选择文件名；确认后可覆盖该文件。

上传在选择或拖入文件后查询目标实际状态，不依赖当前目录的缓存或已加载分页。上传文件夹时递归检查内部文件和子文件夹：两边都是文件夹则合并，不把该文件夹本身列为冲突；同名文件、以及文件与文件夹互相挡住时才列出。没有同名项目就直接开始；发现同名文件或文件夹时才列出冲突项并询问处理方式，默认选中覆盖同名文件。所选策略只应用于预检测发现的冲突项，其余项目始终禁止覆盖。预检测失败时不开始上传；检测后或提交时新出现同名项目，该项失败并提示用户重新检查，保留已有数据。

| 策略 | 行为 |
| --- | --- |
| 提示冲突 | 保留两边内容，该项失败，批量中的其他项继续 |
| 覆盖 | 同名普通文件校验后替换；文件夹合并并保留目标独有内容。文件/文件夹互相冲突或符号链接不覆盖 |
| 跳过 | 已有目标时跳过整个顶层项目（包含已有文件夹），任务显示「已跳过」；移动也保留源内容 |
| 自动改名 | 使用 `名称 (1).扩展名` 等可用名称，任务记录保存实际目标。可在源位置复制出副本 |

覆盖不能撤销。传输先写临时文件并校验；本地发布前复核目标状态，S3 使用 ETag 条件写入，不支持条件写入的服务会报错。取消或校验失败时尚未发布的内容被清理。目录操作没有整体回滚，失败或取消会保留此前已经完成的文件；移动仍须校验完成后才清理源内容。外部程序与本地文件系统的最后一次检查和替换之间没有跨进程事务。

目录浏览通过 `list_entries_page` 每页返回 200 项，滚动到底部自动加载下一页；表格仅渲染可见行及少量缓冲行。跨屏 Shift 连选和框选保留支持，Cmd/Ctrl+A 只选择已经加载的项目，底栏会明确显示加载进度。下一页失败保留已加载内容和选择，可重试或刷新。复制/移动目标中的文件夹使用上一页/下一页按钮。

对象存储进入目录时默认「快速浏览（服务顺序）」，复制/移动目标中的对象存储目录也按需读取。每次仅读取下一批结果，首屏无需扫描整个目录；已返回的页面缓存在临时 SQLite 中，重复请求复用该页面，网络失败可从相同游标重试。未列完时只显示已加载数量，列完后才显示精确总数；详情和预览也不会将部分数量当作总数。快速浏览保持服务返回顺序，文件夹可能分布在不同页，后续页沿服务游标读取，不提供整个目录的固定快照。

名称筛选、隐藏文件开关和名称/大小/修改时间排序覆盖整个当前目录。选择名称/大小/修改时间排序，或输入名称筛选时，后端按最多 500 项迭代列举结果，以临时 SQLite 批量保存和排序，文件夹优先；这类全目录查询仍需遍历当前层。翻页复用排序快照，刷新重新扫描。最多保留 8 份排序快照和 8 个快速浏览会话、有效期 30 分钟，同时最多构建 2 份排序快照；失效后提示刷新。排序快照页不会混入外部修改后的另一版目录。

远程目录自动刷新默认关闭，避免进入目录和后台轮询时反复全量扫描。可手动刷新或从更多操作开启自动刷新；本地目录仍默认每 5 秒检查变化。应用自身的文件操作会继续触发相关目录刷新。窗口重新获得焦点不再自动重新列举已加载页面。

验证：

- `make check`、`make test`：本地覆盖/跳过/改名、取消/并发修改保护、合并目录、并发自动改名、1,205 项目录的分页/筛选/排序/游标授权。
- `FILO_S3_TEST_CONFIG="$HOME/.config/filo/rustfs.json" cargo test -p storage-application --test s3_integration -- --ignored --nocapture`：RustFS 覆盖与条件竞争、跳过移动、自动改名和分页，使用独立测试 Prefix。
- Vite 运行后 `ego-browser nodejs < scripts/test-paging-conflicts.mjs`：3,000 项的虚拟列表、跨屏选择、分页错误恢复、全目录筛选排序、450 个目标文件夹分页、冲突策略与 900px 窗口布局。使用模拟 IPC，不修改真实文件。
- `cargo test -p storage-application listing -- --nocapture`：50,000 项的按需读取、页面重放、网络失败重试、游标边界、精确总数、空过滤页和全目录筛选。
- `cargo test -p provider-opendal s3::listing`：S3 缓冲结果优先返回，后续网络失败不丢弃已返回结果，以及原有路径/分页验证。
- `ego-browser nodejs < scripts/test-large-directory-streaming.mjs`：模拟 50,000 项目录的首屏请求数、远程自动刷新默认关闭、虚拟列表、跨屏选择、分页重试、数量显示、排序/筛选切换和前缀跳转。
