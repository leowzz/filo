# 同名冲突与大目录

复制、移动（含批量）、重命名和上传弹窗提供「遇到同名项目」选项，本次操作统一使用所选策略，默认仍拒绝冲突。下载通过系统保存窗口选择文件名；确认后可覆盖该文件。

| 策略 | 行为 |
| --- | --- |
| 提示冲突 | 保留两边内容，该项失败，批量中的其他项继续 |
| 覆盖 | 同名普通文件校验后替换；文件夹合并并保留目标独有内容。文件/文件夹互相冲突或符号链接不覆盖 |
| 跳过 | 已有目标时跳过整个顶层项目（包含已有文件夹），任务显示「已跳过」；移动也保留源内容 |
| 自动改名 | 使用 `名称 (1).扩展名` 等可用名称，任务记录保存实际目标。可在源位置复制出副本 |

覆盖不能撤销。传输先写临时文件并校验；本地发布前复核目标状态，S3 使用 ETag 条件写入，不支持条件写入的服务会报错。取消或校验失败时尚未发布的内容被清理。目录操作没有整体回滚，失败或取消会保留此前已经完成的文件；移动仍须校验完成后才清理源内容。外部程序与本地文件系统的最后一次检查和替换之间没有跨进程事务。

目录浏览通过 `list_entries_page` 每页返回 200 项，滚动到底部自动加载下一页；表格仅渲染可见行及少量缓冲行。跨屏 Shift 连选和框选保留支持，Cmd/Ctrl+A 只选择已经加载的项目，底栏会明确显示加载进度。下一页失败保留已加载内容和选择，可重试或刷新。复制/移动目标中的文件夹使用上一页/下一页按钮。

名称筛选、隐藏文件开关和名称/大小/修改时间排序覆盖整个当前目录，文件夹优先。后端按最多 500 项迭代本地目录/S3 列举结果，以临时 SQLite 保存和排序，避免整个目录常驻内存或一次 IPC 返回。首次查询及更改筛选/排序仍需遍历当前层；翻页复用快照，刷新重新扫描。最多保留 8 份快照、有效期 30 分钟，同时最多构建 2 份；失效后提示刷新。快照页不会混入外部修改后的另一版目录。

验证：

- `make check`、`make test`：本地覆盖/跳过/改名、取消/并发修改保护、合并目录、并发自动改名、1,205 项目录的分页/筛选/排序/游标授权。
- `FILO_S3_TEST_CONFIG="$HOME/.config/filo/rustfs.json" cargo test -p storage-application --test s3_integration -- --ignored --nocapture`：RustFS 覆盖与条件竞争、跳过移动、自动改名和分页，使用独立测试 Prefix。
- Vite 运行后 `ego-browser nodejs < scripts/test-paging-conflicts.mjs`：3,000 项的虚拟列表、跨屏选择、分页错误恢复、全目录筛选排序、450 个目标文件夹分页、冲突策略与 900px 窗口布局。使用模拟 IPC，不修改真实文件。
