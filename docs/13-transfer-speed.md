# 上传和下载速度设置

在「设置 → 传输速度」分别填写上传、下载上限，点击「保存速度设置」。单位为 KiB/s，1024 KiB/s = 1 MiB/s；默认值 0 表示不限速。「恢复不限速」将两个输入值设为 0，保存后应用。

- 每个方向采用全局共享额度，三个并行任务不会各自获得完整上限。
- 保存后现有任务和后续任务共用新设置，重启后保留。保存失败不会改变正在使用的限制。
- 限制 S3 数据读写，包括上传、下载、复制/移动中的流式传输、远程校验读取，以及超过 5 GiB 对象发布时的流式读写。
- 本地文件互拷、元数据请求和 S3 服务端复制不消耗上传/下载额度。
- 这是 Filo 数据流的平均速度限制。SDK 分片缓存、系统缓存和网络缓冲会造成短时流量波动，并非操作系统级流量整形。

配置保存在 `transfer_settings` 单行表，迁移 `0003_transfer_settings.sql` 为既有安装初始化不限速。两个方向各持有一个共享额度池；等待可取消、修改限速会唤醒等待任务。低速时缩小复制块，避免任务进度长时间不更新。

验证：`cargo test --workspace` 覆盖共享额度、方向隔离、运行中修改、取消等待、读取完整性和持久化。在 Vite 启动后执行 `ego-browser nodejs < scripts/test-transfer-settings.mjs`，验证设置页面默认值、独立保存、重新加载、输入校验、保存失败和恢复不限速。
